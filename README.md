# 发票 PDF 工具箱

> 电子发票 A4 转 A5、多张合并一页、一键打印 —— 纯前端，文件不上传服务器。

![screenshot](https://img.shields.io/badge/纯前端-无需后端-2563eb) ![license](https://img.shields.io/badge/license-MIT-green)

## 在线使用

**https://000221.github.io/invoice-pdf-tool/**

打开即用，不需要下载安装。所有处理都在你的浏览器里完成，发票文件不会上传到任何服务器。

## 为什么做这个

从邮箱下载的电子发票 PDF 通常是 **A4 页面，但实际内容只占上半部分**（标准票面约 210×140mm）。直接打印，一张 A4 只印一张票，纸张浪费一半；想省纸又得手动 PS 排版。

pdf24 之类的在线工具集没有针对发票的版式处理，所以写了这个。

## 核心思路

裁掉 A4 上的空白后，发票本体是一张**横向**的票（比例约 1.5:1）。所以最省纸的排法是 **A4 纵向、上下两张** —— 发票宽度正好撑满 210mm，字号接近原始大小，比"整页缩一半"大得多。

工具会自动判断横竖方向选择排法，也支持手动指定。

## 功能

### 1. 发票合并打印

- 批量拖入 PDF / 图片，每个文件的所有页面都会被加入
- **智能裁剪**：逐页扫描内容像素包围盒，自动去掉空白边
- **自动排版**：横版发票 → A4 纵向上下两张；竖版 → A4 横向左右并排
- 支持每页 1 / 2 / 4 张、A5 单页、自定义边距与间距
- **裁切辅助线**三种模式：仅合并之间（两张相接处画一条淡虚线，末页不满时不画多余线）、每张四边全框、不打印
- 拖拽缩略图调整顺序，支持单独旋转

### 2. PDF 合并

按顺序首尾相接，保持原始页面尺寸（矢量合并，文字不糊）。

### 3. PDF 拆分

- 每页拆成单独文件，打包 zip 下载
- 提取指定页码范围（如 `1-3,5,8-10`）
- 每 N 页拆一份

### 4. 图片转 PDF

JPG / PNG / WebP 按顺序排版成 PDF。

## 使用

### 方式一：在线使用（推荐）

直接打开 https://000221.github.io/invoice-pdf-tool/ ，无需安装。

### 方式二：下载到本地

```bash
git clone git@github.com:000221/invoice-pdf-tool.git
```

或从 [Releases / 仓库首页](https://github.com/000221/invoice-pdf-tool) 下载 ZIP，解压后双击 `index.html` 即可，无需安装任何依赖。

首次打开需要联网加载 PDF 引擎（约 3MB，来自 CDN），加载后本会话不再请求。

`demo/` 目录里有 4 份模拟电子发票可以直接拖进去试。

### 打印设置

| 项目 | 建议值 |
|---|---|
| 纸张 | A4 |
| 方向 | 跟随工具提示（纵向或横向） |
| 缩放 | 100% / 实际大小（**不要**勾"适应页面"） |
| 页边距 | 无 / 默认 |

默认留了 5mm 页面边距，避免发票边框落进打印机不可打印区被切掉。如果打印预览里还是切边，把「页面边距」调大再生成。

## 技术实现

纯浏览器端，无后端、无上传。

| 用途 | 库 |
|---|---|
| PDF 页面渲染 | [pdf.js](https://mozilla.github.io/pdf.js/) 3.11 |
| PDF 生成 / 合并 / 拆分 | [pdf-lib](https://pdf-lib.js.org/) 1.17 |
| 拆分打包 | [JSZip](https://stuk.github.io/jszip/) 3.10 |

处理管线：pdf.js 渲染页面到 canvas → 检测内容包围盒并裁剪 → 编码 JPEG → pdf-lib 按目标版式排版输出。

几个实现细节：

- **边界检测**：把整页降采样到 520px 宽再做行列投影，非白像素阈值 248、行密度阈值 0.5%。几乎铺满整页时判定为扫描件，不裁剪。
- **格子自适应**：单列排版时按 `cellH = cellW / 平均宽高比` 收紧格子高度，避免格内留白；整体居中。
- **栅格化而非矢量嵌入**：裁剪、旋转、坐标系处理在 canvas 上更可控；200 DPI 打印质量足够。
